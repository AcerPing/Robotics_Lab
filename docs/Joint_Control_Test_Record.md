# Robotics Lab｜關節與時間控制測試紀錄

## 1. 實驗目的

驗證 PyBullet 人形機器人能否依照 Action Frame 定義，執行連續關節姿態控制，並量測目標角度與實際角度之間的差異。

## 2. 實驗環境

- 模擬平台：PyBullet
- 人形模型：`humanoid/humanoid.urdf`
- 執行環境：Windows／Python 虛擬環境
- 模擬時間步長：1/240 秒
- 動作插值方法：Smoothstep
- 模型設定：Fixed Base
- GUI 相機角度：Yaw 90°
- 主要控制關節：右肩膀 Joint ID 03、右手肘 Joint ID 04

本研究使用 PyBullet 人形模型進行動作控制概念驗證，並非直接進行 Alpha 1S 實體機器人測試。

## 3. Action Frame 設計

| Frame | 動作名稱 | 右肩膀 Z | 右手肘 | 動作時間 | 保持時間 |
|---|---|---:|---:|---:|---:|
| 01 | Initial Pose | 0° | 0° | 2.0 s | 0.5 s |
| 02 | Raise Right Arm | 45° | 0° | 2.0 s | 0.5 s |
| 03 | Wave Right Arm - Bend | 45° | 30° | 1.0 s | 0.3 s |
| 04 | Wave Right Arm - Extend | 45° | 0° | 1.0 s | 0.3 s |

註：Frame 01 的 duration 與 hold 為資料欄位設定；本次 GUI 程式先設定初始姿態並等待 3 秒，並未依該欄位執行一次動作過渡。

## 4. 關節控制測試結果

下表採用 Step 7-B-6A-7-3 的 After Hold 實驗紀錄。

| 動作階段 | 關節 | 目標角度 | 實際角度 | 絕對誤差 |
|---|---|---:|---:|---:|
| Frame 01 → 02 | 右肩膀 Z | 45° | 44.800512° | 0.199488° |
| Frame 01 → 02 | 右手肘 | 0° | 0.001227° | 0.001227° |
| Frame 02 → 03 | 右肩膀 Z | 45° | 44.999966° | 0.000034° |
| Frame 02 → 03 | 右手肘 | 30° | 30.000085° | 0.000085° |
| Frame 03 → 04 | 右肩膀 Z | 45° | 44.999613° | 0.000387° |
| Frame 03 → 04 | 右手肘 | 0° | 0.000000° | 0.000000° |

## 5. 測試結果分析

本次實驗成功執行 Frame 01 → Frame 02 → Frame 03 → Frame 04 的連續動作流程。

Frame 02 完成後，右肩膀的實際角度為 44.800512°，與目標值 45° 的差距為 0.199488°。

Frame 03 完成後，右手肘實際角度為 30.000085°，與目標值 30° 的差距為 0.000085°。

Frame 04 完成後，右手肘返回 0.000000°，顯示簡化的彎肘與伸肘往返動作可以完成。

以上結果為各影格保持階段結束時的量測值，不代表整段運動期間的最大誤差或平均誤差。

## 6. 16 個邏輯控制欄位映射

本專題定義 16 個軟體邏輯控制欄位，並完成與 PyBullet URDF 的靜態一致性查核。

- 邏輯控制欄位：16
- 對應可活動關節：12
- URDF Joint 總數：15
- 模型旋轉自由度：28
- 靜態映射驗證：16/16 PASS
- 驗證方法：PyBullet DIRECT 模式讀取 Joint ID、名稱及型態

16 個邏輯欄位不是 16 個獨立的實體伺服馬達，也不代表所有欄位均已完成動態控制測試。

## 7. 實驗限制

1. 人形模型使用固定基座，不涉及自主平衡與步行。
2. 模型並非 Alpha 1S 實體機器人。
3. 目前動作控制主要驗證右肩膀與右手肘。
4. 揮手動作採簡化的彎肘、伸肘設計，與真人揮手仍有差異。
5. 16 個邏輯控制欄位已完成靜態映射，尚未逐一驗證動態控制。
6. 模擬結果尚未涵蓋不同隨機條件、控制負載或真實硬體誤差。

## 8. 階段性結論

本階段已完成 PyBullet 人形機器人四個 Action Frame 的連續動作控制，以及 16 個邏輯控制欄位與 URDF 的靜態映射驗證。

測試結果顯示，右肩膀與右手肘能在指定保持時間後接近目標角度，並成功完成簡化的舉手與揮手往返動作。

後續工作將以實驗證據整理、模擬影片歸檔及專題報告撰寫為主，不將目前成果誤述為實體機器人的自主動作控制。
