## 8. 影片證據使用限制

1. 影片可作為 PyBullet GUI 模擬姿態變化的視覺證據。
2. 關節角度精度應以 PowerShell 量測紀錄為依據，而不是由影片畫面估算。
3. 模擬模型為固定基座，不代表自主站立、平衡或步行成功。
4. 簡化揮手是右手肘彎曲與伸直，不等於已完成擬真人形揮手動作。
5. 16 個邏輯欄位目前完成靜態映射，並非全部完成動態控制測試。
6. 不應將模擬影片稱為 Alpha 1S 實體操作錄影。
